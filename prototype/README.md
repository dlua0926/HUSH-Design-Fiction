# HUSH — Private Hours

A fictional home Wi-Fi privacy router. Open `index.html` in a browser; no installation is needed. All interactions are simulated. No real payment, tracking protection or network connection is performed. The optional Google Fonts request contains no search queries; system fonts work offline.

## Demonstration
1. Begin with zero hours remaining, renewal in three days, eleven connected devices.
2. Continue without protection. Submit a simulated search and see a shared browsing signal.
3. Buy an extra hour via simulated checkout. A real-time countdown begins; earlier shared signals remain.
4. Search again. The new activity is protected; its query is not retained in the demonstration ledger.
5. Use Demo controls to jump to the last ten seconds and watch protection expire without disconnecting Wi-Fi.
6. Restart and try paying before searching. Switch networks to see HUSH's coverage boundary.
7. Inspect connected devices, allowance details and the monthly report.

State is stored in this browser tab's session storage. Restart clears it. Monthly report baseline figures are fictional; demonstration events are shown separately in the browser view. Report categories sum to 1,284; 63 advertising profile updates are a separate outcome measure.

World rules: the household shares 20 wall-clock hours each month, extra continuous hours cost $3.99, and only new tracking/identity-linked profile sharing by participating services is paused. Existing data and deliberately submitted service information are outside this protection. This prototype does not assume a physical router alone can enforce these rules on today's platforms.
